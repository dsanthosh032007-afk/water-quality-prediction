Project Overview

About Water Quality Prediction & Safety Detection

Clean, potable water is fundamental to human health and ecological sustainability. This application utilizes Machine Learning to rapidly assess water potability based on key chemical and physical indicators defined by the World Health Organization (WHO).

The Dataset

The model is trained on the standard Water Potability Dataset containing 3,276 water body measurements. Features include pH, Hardness, Solids, Chloramines, Sulfate, Conductivity, Organic Carbon, Trihalomethanes, and Turbidity.

Machine Learning Pipeline

Our preprocessing pipeline uses median value imputation to handle non-random missing data, followed by Z-score standard scaling. Classification is performed using an optimized Random Forest Classifier ensemble for maximum generalization.

Key Safety Parameters

  • pH: Measures hydrogen-ion concentration (WHO target: 6.5 - 8.5).
  • Solids (TDS): Total dissolved minerals and salts in ppm.
  • Chloramines: Disinfectant levels to prevent pathogen growth.
  • Trihalomethanes: Chlorination by-products requiring strict upper bounds.
